Using Sempere

Spotlight

An opt-in switch that puts note titles, and optionally their text, in Apple's Spotlight search. What it copies, where it lives, and how it is removed.

Spotlight is part of iOS and macOS, not part of Sempere. By default Sempere puts nothing in it. If you turn it on, a search from the Home Screen, the Mac’s Spotlight or Siri finds your notes, and a result opens the note in Sempere.

This is a trade. Spotlight’s index belongs to the system and is not protected by your vault’s encryption. What you copy into it can be read by anyone or anything that can read it on that device, including system features such as Siri and Apple Intelligence. The switches say so each time you turn them on. If a note must stay inside the vault’s encryption, leave Spotlight off.

Two switches

Open Settings ▸ General ▸ Spotlight. The switches are off by default, and they apply to the open vault on this device only. They are not synced: turning one on here never puts anything in Spotlight on your other devices.

  • Show This Vault’s Notes in Spotlight copies each note’s title, notebook, tags and dates.
  • Include Note Text (shown once the first switch is on) also copies the note’s text: recognized handwriting, typed text, PDF text and equations’ LaTeX, and recording transcripts when Search Recording Transcripts is on. It copies at most 20,000 characters per note.

Notes in Recently Deleted are not copied. At most 50,000 notes of a vault are, newest first, and Settings says how many older ones were left out.

When it is removed

Sempere removes what it copied when you turn the switch off, delete a note, change the vault’s keys (re-encrypt), remove this device from the vault, or remove the vault from the app. It also turns Spotlight off and removes the items by itself if this device loses the vault’s key, is removed from the vault, or can no longer verify the vault’s device list. A vault opened only with the recovery key cannot use Spotlight, and the demo vault is never added.

With the CLI

sempere spotlight plan lists exactly what the switches would copy for a vault, without writing anything:

sempere spotlight plan                       # titles, notebooks, tags and dates
sempere spotlight plan --text --transcripts  # with Include Note Text

Only the app can fill Spotlight; the command is a way to see, before you turn a switch on, what would leave the encryption. See the CLI.
