Support

Contact

  • Questions and bug reports: open an issue at github.com/anthonytw/sempere/issues. Please never paste a real key or real notes; a description of what you did and what happened is enough.
  • Security problems: report them privately, as described in SECURITY.md.
  • Contributing: see CONTRIBUTING.md.

Sempere is a volunteer-run project; replies can take a while. There is no account and no server, so nobody can reset your key or read your notes. Read the first two answers before you need them.

Reporting a crash

  • iPhone, iPad: Settings, Privacy & Security, Analytics & Improvements, Analytics Data. Find the files named Sempere-<date>.ips, share one, and attach it to a GitHub issue.
  • Mac: Console.app, Crash Reports, or ~/Library/Logs/DiagnosticReports (Sempere-*.ips).
  • Optional: turn on "Share with App Developers" in the same Settings screen, and Apple forwards crash logs to the developer.

Frequently asked questions

I lost my key. Can you recover my notes?

No. Your notes are encrypted to keys that only you hold, and the developer never has a copy. If every copy of the key is gone, nobody can decrypt the notes. Save a paper recovery kit (the key as a QR code and as text) from Settings, Device Keys, Save Key… (CLI: sempere keys paper), keep it somewhere safe, and keep a backup on another drive or provider.

How do I back up my notes?

In Settings, Backups copies the vault's encrypted files to a folder you choose (another drive or another cloud provider), only what is new each time, and can verify the copy. The CLI does the same with sempere backup. A backup contains no plaintext, so it can go anywhere, and it is itself a vault.

How do I use my notes on another device?

Put the vault folder where both devices can reach it (iCloud Drive is the easy way), then give the second device a key that the vault lists. Settings, Device Keys can save this device's key or make a new one for another device; the device list updates and the notes are re-encrypted for it.

Does Sempere sync?

Sync is a folder: the app reads and writes files and whatever service holds the folder moves them. Edits from several devices merge, and sync tools never see a conflict copy. From the command line you can also mirror a vault to a WebDAV share with sempere sync webdav.

What is sent to the developer, or to anyone?

Nothing. There is no server, no account, no analytics and no crash reporting. Handwriting recognition and transcription run on your device. The only network traffic the system may make for you is Apple downloading a speech model for your language, which contains none of your data. Read the privacy policy.

Which devices do I need?

iPadOS, iOS or macOS 26 or later for the apps; macOS 26 or later or Linux for the CLI. The iPad is the writing device (Apple Pencil); the iPhone is a reader with annotation; the Mac app is the iPad app built with Mac Catalyst. See the specs.

Can I import my Notability notes?

Yes. The importer reads the raw notes of a personal Notability backup: .note and .ntb files, the folders that contain them, or the backup's zip files (for example from Google Drive), wherever the local copy lives. Notability's PDF exports are not what it imports. It brings strokes, PDF backgrounds, images, typed text, recordings and recognised text, and can be run again safely; notes already imported are skipped. It is in the app (File menu on the Mac, the note list's toolbar elsewhere) and in sempere import notability. Notability is a trademark of its owner; Sempere is not affiliated.

Can I read my notes without Sempere?

Yes. Every note is a standard age file inside a gzip, so with your key, age 1.3 or later, gunzip and jq you can read it. The recovery kit prints the steps. The sempere CLI exports PDF, SVG, PNG, Markdown and HTML on macOS and Linux, and the web viewer opens a vault in a browser.

Why does handwriting search not find a word?

Recognition is opt-in and runs on the device: use "Recognize All Notes" in the app, or the CLI on macOS (it uses Apple Vision; not available on Linux). Search then covers recognised text, titles, tags, notebooks, typed text, PDF text and transcripts.
