Specs

Taken from the project's documentation and code.

Platforms

iPad, iPhone, MaciPadOS, iOS and macOS 26 or later. The Mac app is the iPad app built with Mac Catalyst, with a menu-bar item for Quick Voice Note and New Note. The iPhone app is a reader with annotation.
CLIsempere: macOS 26 or later (universal binary), or Linux (static binary, x86_64 and aarch64).
Web viewerRead-only, runs in the browser; decrypts in the page.
LanguagesApp: English, Spanish. CLI and web viewer: English.
LicenceGPL-3.0-or-later with an App Store exception (LICENSE-EXCEPTION). Source: github.com/anthonytw/sempere.

Linux (CLI)

The CLI is a complete vault client on Linux. Everything that does not need Apple frameworks or a pen runs there.

AreaOn Linux
Vaults and keysCreate, open, verify, list; generate, show, export keys; add, remove and replace device keys.
Encryptionage v1 with the ML-KEM-768 + X25519 recipient (swift-crypto on Linux, CryptoKit on Apple platforms). Same files, same keys.
NotesCreate, rename, tag, move, history and restore, pages, items, search.
AttachmentsImages, PDFs, text, equation source, video, recordings, transcripts.
ImportThe same importers as on macOS (see Input and import formats).
ExportPDF, SVG, PNG, Markdown, HTML, JSON. PDF page backgrounds in SVG and PNG use Poppler if installed.
Backup and recoveryBackup, verify, restore; paper recovery kit; recover one file with stock age.
SyncWebDAV, two-way or push-only mirror.
Not on Linuxrecognize (Apple Vision) and transcribe (Apple Speech) report an error. There is no GUI. For video clips, pass --poster with an image: Linux cannot make the poster frame itself.

Input and import formats

InkApple Pencil and touch. Stored as vector strokes in an open JSON format (PencilKit control points).
ImagesJPEG and PNG. Location and camera metadata is removed by default. HEIC from Photos is converted to JPEG.
PDFImported as a new note, or pages inserted into a note. Encrypted PDFs are stored without the password.
VideoMP4 and QuickTime, H.264 or HEVC.
Text, equationsText boxes in any script. Equations as LaTeX.
NotabilityImports the raw notes of a personal Notability backup: .note and .ntb files, the folders that hold them, or the backup's zip files (for example from Google Drive), wherever the local copy lives. Notability's PDF exports are not imported. Notability is a trademark of its owner; Sempere is not affiliated.

Export formats

AppPDF, PDF with attachments (recordings and transcripts embedded), PNG pages, Markdown text. One note, a selection, a notebook or the vault; to a folder or a zip.
CLIPDF, SVG, PNG, Markdown (Obsidian-style folders), single-file HTML, JSON.
BackupsIncremental copy of the encrypted files, checked by a verify step. A backup is itself a vault. The CLI also writes a tar archive.

Cryptography

PrimitivesX25519, ML-KEM-768, ChaCha20-Poly1305, HKDF-SHA-256, HMAC-SHA-256, Ed25519, ML-DSA-65, scrypt. From CryptoKit (Apple platforms) and swift-crypto (Linux). The web viewer uses typage (age-encryption), @noble/post-quantum, @noble/curves and WebCrypto.
age v1Sempere implements the age v1 file format itself (Sources/Age): header and MAC, X25519, scrypt and ML-KEM-768 + X25519 recipient stanzas, STREAM payload, armor, Bech32 keys. Checked against the C2SP CCTV test vectors and against the reference age tool.
Vault formatSempere's own, on top of age: docs/format.md. HMAC tags under a per-vault secret on revisions, blobs and the device list; secret changes are linked by Ed25519 and ML-DSA-65 signatures.
RecipientsHybrid post-quantum only: ML-KEM-768 + X25519 (age1pq1…). Details: docs/post-quantum.md. Reading a note by hand needs age 1.3 or later.

Storage

VaultA folder named Something.sempere. There is no server of ours. The files are already encrypted, so a storage provider sees only ciphertext, file names, sizes and times.
AppOn the device, in iCloud Drive, or in any folder the Files app offers (for example an SMB share on a NAS).
CLI and viewerAny folder. sempere sync webdav mirrors a vault to a WebDAV share (for example a self-hosted Nextcloud); the viewer reads a vault from a static URL, a WebDAV share or a local folder.
SettingsSettings are kept in the vault as one encrypted file, with optional per-device overrides.
MergingNotes are append-only logs. Edits from several devices merge, and sync tools never create conflict copies.
