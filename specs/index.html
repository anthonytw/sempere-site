Specs

Platforms, formats, cryptography and storage.

Platforms

iPad, iPhone, MaciPadOS 27, iOS 27 and macOS 27 (Mac Catalyst) or later. The Mac app is built with Mac Catalyst and has an optional menu-bar item: Quick Voice Note, New Note, Open Sempere.
CLIsempere: macOS 27 or later (universal binary), or Linux (static binary, x86_64 and aarch64).
Web viewerRead-only, runs in the browser; decrypts in the page.
LanguagesApp and web viewer: English, Spanish. CLI: English.
LicenseGPL-3.0-or-later with an App Store exception (LICENSE-EXCEPTION). Source: github.com/anthonytw/sempere.

Linux (CLI)

The CLI is a complete vault client on Linux. Everything that does not need Apple frameworks or a pen runs there.

Input and import formats

InkApple Pencil and touch. Stored as vector strokes in an open JSON format (PencilKit control points).
ImagesJPEG and PNG. Location and camera metadata is removed by default. HEIC from Photos is converted to JPEG.
PDFImported as a new note, or pages inserted into a note. Encrypted PDFs are stored without the password.
VideoMP4 and QuickTime, H.264 or HEVC.
Text, equationsText boxes in any script. Equations as LaTeX.
NotabilityImports the raw notes of a personal Notability backup: .note and .ntb files, the folders that hold them, or the backup's zip files (for example from Google Drive), wherever the local copy lives. Notability's PDF exports are not imported.

Export formats

AppPDF, PDF with attachments (recordings, transcripts and video clips embedded), PNG pages, Markdown text, Media (a folder per note with its recordings, transcripts, clips, images and PDFs). Through the share sheet or Save to Files; or PDF, PDF with attachments, PNG and Media for a selection, a notebook or the vault, to a folder or a zip.
CLIPDF, SVG, PNG, Markdown (Obsidian-style folders), single-file HTML, JSON, Media.

Cryptography

PrimitivesX25519, ML-KEM-768, ChaCha20-Poly1305, HKDF-SHA-256, HMAC-SHA-256, Ed25519, ML-DSA-65, scrypt. From CryptoKit (Apple platforms) and swift-crypto (Linux). The web viewer uses typage (age-encryption), @noble/post-quantum, @noble/curves and WebCrypto.
age v1Sempere implements the age v1 file format itself (Sources/Age): header and MAC, X25519, scrypt and ML-KEM-768 + X25519 recipient stanzas, STREAM payload, armor, Bech32 keys. Checked against the C2SP CCTV test vectors and against the reference age tool.
Vault formatSempere's own, on top of age: docs/format.md. Every file encrypted once, to a vault identity derived from a per-epoch vault key, which vault.json wraps for each device and for the recovery key. HMAC tags under keys derived from the vault key on revisions, blobs and the device list; the device list signed by the home device (P-256 and ML-DSA-65), epochs linked by Ed25519 and ML-DSA-65 signatures.
KeysHybrid post-quantum only: ML-KEM-768 + X25519 (age1pq1…). Details: docs/post-quantum.md. Device keys are made on each device and never leave it; signing keys in the Secure Enclave where there is one. Reading a note by hand needs age 1.3 or later.

Storage

VaultA folder named Something.sempere. The files are already encrypted, so a storage provider sees only ciphertext, file names, sizes and times.
AppA complete copy of each vault inside the app on every device, which works offline. Any number of sync targets per vault, synced both ways: a shared .sempere folder in iCloud Drive, in any location the Files app offers (for example an SMB share on a NAS) or on a drive, or a WebDAV server over HTTPS (a self-signed certificate is accepted only after you trust its fingerprint; the password is kept in the Keychain). Other devices open the target and join by approval. Every received file is checked before it is placed.
BackupsA <Name>.sempere-backup snapshot of the encrypted files, for recovery. Incremental, checked by a verify step. Nothing syncs from it, and it is never a sync target. The CLI also writes a tar archive.
CLI and viewerAny folder. sempere sync webdav and sync folder sync a vault two ways with a WebDAV share (for example a self-hosted Nextcloud) or another folder; the viewer reads a vault from a static URL, a WebDAV share or a local folder.
SettingsSettings are kept in the vault as one encrypted file, with optional per-device overrides.
MergingNotes are append-only logs. Edits from several devices merge, and sync tools never create conflict copies.
