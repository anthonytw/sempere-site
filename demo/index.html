Live demo

The Sempere web viewer with a sample vault made by the sempere CLI. Paste the key; the browser decrypts the notes.

This is a demo vault. The key is public on purpose. It opens only this sample vault, which holds invented notes, a public-domain image and a PDF made for the demo. Your own vault key must never be shared like this.

Then paste it into the viewer's key box and choose Unlock. Try searching for pendulum, Lisbon or Spanish.

Open the viewer on its own page if the frame is cramped on your screen.

What you are looking at

  • The vault is a folder of encrypted files, served here as static files: vault.json lists the public key it is encrypted to, and each note lives in its own folder of .age files. Fetch one and you will see only ciphertext.
  • The viewer is read-only and runs entirely in your browser. It has a strict Content-Security-Policy (no inline script, no eval), and it never sends the key anywhere.
  • Handwriting, text boxes and the equation were put there by scripts/make-demo-vault.sh; ink in the app comes from Apple Pencil. Textures such as pencil grain are drawn more simply here than in the app.
  • To read a real vault, host the viewer next to it (docs/web-viewer.md), or use the sempere CLI.

Source for the sample: github.com/anthonytw/sempere and this site's repository.
